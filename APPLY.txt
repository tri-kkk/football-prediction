시간 범위 수정 + 배경음 추가

1) API 2개 덮어쓰기
   shorts-daily-route.ts  → app/api/admin/shorts-daily/route.ts
   shorts-result-route.ts → app/api/admin/shorts-result/route.ts
2) Remotion 덮어쓰기
   remotion/  scripts/
3) npm run dev 재시작 (또는 배포)


=========================================
[1] 끝난 경기가 "오늘의 픽" 에 들어가던 문제
=========================================

유럽 축구는 한국시간 새벽에 열립니다.
"오늘" 을 KST 달력 하루(00:00~23:59)로 자르면
아침에 렌더할 때 오늘 새벽에 이미 끝난 경기가 포함됩니다.
(AT 마드리드 경기가 그 케이스였습니다)

수정: 지금(now) 이후에 시작하는 경기만 봅니다.
      범위는 앞으로 30시간 — 오늘 밤 경기와 내일 새벽 경기가 한 묶음으로 들어옵니다.

  shorts-daily-route.ts 의 upcomingRange(30)

야구도 같은 필터를 넣었습니다. 오후에 렌더해도
이미 시작한 경기는 픽에서 빠집니다.

주말 TOP 5 도 토·일에 돌리면 이미 끝난 경기를 제외합니다.


=========================================
[2] 화면 문구가 경기 시간대를 반영합니다
=========================================

  전부 오늘        →  "유럽 축구 · 오늘 분석"
  오늘+내일 걸침   →  "유럽 축구 · 오늘 밤 ~ 내일 새벽 분석"
  전부 내일 새벽   →  "유럽 축구 · 내일 분석"

API 응답의 windowLabel 로 내려옵니다.


=========================================
[3] 성적표가 최신 경기를 놓치던 문제
=========================================

"어제 달력 하루" 로 자르면 오늘 새벽에 끝난 가장 최신 경기가
어제에 안 잡혀서 하루 늦게 성적표에 나왔습니다.

수정: 지금 기준 지난 36시간 내 종료된 경기를 봅니다.
      새벽 경기가 그날 아침 성적표에 바로 들어갑니다.

  shorts-result-route.ts 의 recentRange(36)


=========================================
[4] 배경음 추가
=========================================

음원이 2분이 넘는데 영상은 20초 안팎이라
그냥 붙이면 재생 중간에 뚝 끊깁니다.
페이드인 0.4초 / 페이드아웃 0.9초를 걸었습니다.

  remotion/components/Bgm.tsx

포맷별 기본 음원 (public/sounds/):
  오늘의 픽    sport-energetic.mp3
  어제 성적표  rockot-cinematic.mp3
  주말 TOP 5   sports-rock.mp3
  빅매치       sport-energetic.mp3

바꾸려면 scripts/render-shorts.mjs 의 DEFAULT_BGM

  # 다른 음원으로
  npm run shorts:render -- --format=daily --group=euro --bgm=leberch-hiphop.mp3
  # 무음으로
  npm run shorts:render -- --format=daily --group=euro --bgm=none

볼륨은 remotion/components/Bgm.tsx 의 volume (기본 0.42)


⚠ 유튜브 저작권 확인
  현재 음원들이 유튜브 상업적 이용까지 허용된 라이선스인지 확인하세요.
  Content ID 클레임이 걸리면 수익화가 막힙니다.
  불확실하면 유튜브 오디오 보관함 음원이 가장 안전합니다.
